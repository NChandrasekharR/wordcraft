01 · What is an agent?

A control loop around a stochastic function

A single model call is one sample of text → text. An agent wraps it in a loop that keeps acting until a goal is met.

Single-shot

Prompt → output

One call, one result. Wordcraft's original "Generate Variant."

Agentic

Loop + tools

The model reasons, calls tools, observes, and continues until done.

The formula

loop + model + toolset

Tools define the agent's action space; the loop gives it persistence.

02 · Agentic patterns

Spend more inference to beat the single sample

Every pattern exploits one of four mechanisms:

Plan-and-execute · orchestrator-workers. (Wordcraft's swarm.)

Iterate

Self-refine · Reflexion · generator-critic feedback loops.

Search

Chain-of-Thought · self-consistency · Tree-of-Thought.

Ensemble

Debate · mixture-of-agents · blackboard · routing.

Plus ReAct (reason → act → observe) — the canonical tool-using loop that grounds reasoning in the real world.

WORDCRAFT
02 · Patterns, in focus

Debate & Tree-of-Thought

Tree-of-Thought

Reframe solving as search over a tree: generate candidate thoughts, score each partial path, explore the best, backtrack from dead ends. Game-playing AI, where the moves and the evaluator are both the model.

Best when the problem branches and you can judge partial progress. Cost = branching × depth.

Debate

Agents argue opposing positions over rounds; a judge decides. The bet: recognizing a strong argument is easier than generating one, and falsehoods are hard to defend under pressure.

Best where correctness is contestable — reasoning, fact-checking. A scalable-oversight technique.

04 · The problem

The function config → output is illegible

You can't form a predictive, causal mental model of it — for four compounding reasons:

Stochastic

Same config, different output. Was it your edit, or chance?

Nonlinear

Many knobs; small changes have huge or zero effect.

Slow & costly

Each experiment is 30s + real money. You can't tinker.

Hidden

You see the ends, not the causal chain between.

Norman's two gulfs, both widened: what do I change? and what did my change do? Today's tools narrow only the second.

WORDCRAFT
05 · The thesis

You don't debug in production

Deploy
↳ requires Trust
   ↳ requires Understanding
      ↳ requires Experimentation
         ↳ requires a venue that isn't production

The missing surface isn't a better trace — it's a lab.

  • Counterfactual legibility — the epistemics: change one thing, see the attributed delta.
  • A testbed — the venue: representative fixtures, no real-world stakes, then promote.

Counterfactual legibility is the instrument. The lab is the venue. Calibrated trust is the goal.

WORDCRAFT
05 · The core claim

Users are doing science without a control group.

No product separates the effect of your change from the effect of the model's randomness. So on every change, run two things — the changed config and a re-run of the unchanged config — and show both deltas side by side.

Noise

Baseline vs. a second baseline sample — what changes from chance alone.

Signal

Baseline vs. your settings — what your edit actually did.

WORDCRAFT
06 · How to test it

The Controlled Experiment

A working prototype in Wordcraft: run current settings once + a neutral baseline twice, then judge signal against noise.

Real effect

Your settings change the text well beyond random variation. The knob does real work.

Marginal

Some effect, but close to the noise floor. Weak evidence.

Within the noise

Barely moves more than chance. Don't trust the difference.

Principles: controlled experiment as the core gesture · a noise baseline always · cheap fast loops · representative fixtures · promotion from lab to prod.
